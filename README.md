\# MCServerBot



MCServerBot 是一个基于 NoneBot2 的 Minecraft 服务器运维机器人，支持 QQ 官方机器人接入，并通过 MCSManager API 管理 Minecraft 服务端。



\## 功能



\- 查询服务器状态

\- 查询在线玩家

\- 查询 Java 内存与 CPU 占用

\- 查询系统内存

\- 查询世界存档与服务端目录占用

\- 查询 TPS

\- 启动 / 停止 / 重启服务器

\- 执行 MCSManager 控制台命令

\- 定时向群聊播报服务器状态



\## 技术栈



\- Python

\- NoneBot2

\- nonebot-adapter-qq

\- MCSManager API

\- psutil

\- httpx
