## 普通玩家查询权限开放

以下 8 个主指令对普通玩家开放，无需加入 `ADMIN_USER_IDS`：

- `/mchelp`（别名 `/ctihelp`）：指令帮助。
- `/whoami`：用户和群聊标识查询，原本已公开。
- `/online`：在线人数。
- `/players`：在线玩家名单。
- `/reportnow`：完整状态报告。
- `/memory`：Java 和系统资源信息。
- `/worldsize`：存档与服务端目录大小。
- `/tps`：TPS 查询。

`/log`、服务器控制、玩家管理、`/reportstatus`、`/reportretry` 共 14 个主指令仍仅管理员可用。公开查询会展示玩家名单及服务器资源信息，但不会授予任意控制台命令权限。

## 从云端 v0.3.0 升级

1. 停止机器人，备份现有项目与 `.env.prod`，备份放到运行目录之外。
2. 下载本版本完整源代码。用新版 `plugins` 目录替换旧版 `plugins`，同步根目录的 `bot.py`、`pyproject.toml`、`requirements.txt`；**保留云端实际 `.env.prod` 和 `.venv`**，不要用示例覆盖生产配置。
3. 在原运行目录执行 `.venv\Scripts\python.exe -m pip install -r requirements.txt`。
4. 确认 `.env.prod` 的 QQ AppID 带英文双引号，然后执行 `.venv\Scripts\python.exe bot.py`。
5. 用不在管理员列表中的 QQ 账号测试 `/online`、`/mchelp`；`/log` 应仍返回“无权限”。

无需修改管理员名单，也无需重新申请平台权限即可应用代码中的访问规则。开放平台的指令介绍可相应标注“普通玩家可用”或“管理员专用”。主动消息权限与本次查询权限开放无关。
